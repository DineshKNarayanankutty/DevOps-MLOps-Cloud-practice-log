# MLOps

## MLflow Run Triage

### Task

Review 10 runs in:

```text
fraud-detection
```

experiment.

---

### Requirements

#### Best Model

Find:

```text
Highest f1_score
where f1_score > 0.85
```

Tag:

```text
review-status=shortlisted
```

---

#### Reject Poor Models

For every run:

```text
f1_score < 0.75
```

Tag:

```text
review-status=rejected
```

---

#### Leave Others Untouched

Runs in:

```text
0.75 ≤ f1_score ≤ 0.85
```

must have:

```text
No review-status tag
```

---

### Learning

This simulates a real ML model review process.

Pipeline:

```text
Experiment
     ↓
Many Runs
     ↓
Metrics Review
     ↓
Shortlist Candidate
     ↓
Promote Model
```

---

### Why F1 Score?

Used when:

```text
Class Imbalance Exists
```

because it balances:

```text
Precision
Recall
```

---

### Real MLOps Workflow

```text

      ↓

      ↓

      ↓
```
