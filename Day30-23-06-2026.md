### Install iptables

Amazon Linux 2023 does not include iptables.

Installed:

```bash
sudo dnf install iptables-services -y
```

Verify:

```bash
iptables --version
```

---

### Enable IP Forwarding

Temporary:

```bash
sudo sysctl -w net.ipv4.ip_forward=1
```

Persistent:

```bash
echo "net.ipv4.ip_forward = 1" | sudo tee -a /etc/sysctl.conf

sudo sysctl -p
```

Verification:

```bash
cat /proc/sys/net/ipv4/ip_forward
```

Expected:

```text
1
```

---

### Configure NAT

Create masquerade rule:

```bash
sudo iptables -t nat -A POSTROUTING -o enX0 -j MASQUERADE
```

Allow forwarding:

```bash
sudo iptables -A FORWARD -i enX0 -o enX0 -m state --state RELATED,ESTABLISHED -j ACCEPT

sudo iptables -A FORWARD -i enX0 -o enX0 -j ACCEPT
```

---

### Save Rules

```bash
sudo service iptables save
```

Alternative:

```bash
sudo iptables-save | sudo tee /etc/sysconfig/iptables
```

Enable service:

```bash
sudo systemctl enable iptables

sudo systemctl restart iptables
```

---

### Verification

Check NAT table:

```bash
sudo iptables -t nat -L -n -v
```

Expected:

```text

```

# Linux

## ACL Management on /etc/hostname

### Objective

Configure ACLs on:

```text
/etc/hostname
```

---

### Requirements

```text
Owner: root
Group: root

Others:
Read Only

ravi:
No Access

garrett:
Read Only
```

---

### Commands Used

Set owner:

```bash
sudo chown root:root /etc/hostname
```

Set permissions:

```bash
sudo chmod 644 /etc/hostname
```

Remove ravi access:

```bash
sudo setfacl -m u:ravi:--- /etc/hostname
```

Grant garrett access:

```bash
sudo setfacl -m u:garrett:r-- /etc/hostname
```

---

### Verification

Ownership:

```bash
ls -l /etc/hostname
```

ACL:

```bash
getfacl /etc/hostname
```

Expected:

```text
user:ravi:---
user:garrett:r--
other::r--
```

---

### Key Learning

ACLs provide:

```text
Per User Permissions
```

without changing:

```text
Owner
Group
Others
```

permissions.
