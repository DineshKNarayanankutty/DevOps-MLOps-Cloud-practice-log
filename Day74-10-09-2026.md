# 2. MLOps — Fraud Amount Metric + Grafana Version Dashboard

## Objective

Add:


# Part A — Metric emitter

File:

```bash
/root/code/monitoring/app/metric_emitter.py
```

Open:

```bash
cd /root/code/monitoring/app
vi metric_emitter.py
```

## Step 1 — Add Counter

After `REQUEST_TOTAL`, add:

```python
FRAUD_AMOUNT_TOTAL = Counter(
    "fraud_amount_usd_total",
    "Total fraudulent transaction amount in USD, labelled by model version.",
    labelnames=["version"],
    registry=REGISTRY,
)
```

Important:

```python
registry=REGISTRY
```

must be present because the application uses its own `CollectorRegistry`.

---

## Step 2 — Increment the Counter

Original loop:

```python
for version in ("v1", "v1", "v1", "v2"):
    REQUEST_TOTAL.labels(version=version, endpoint="/predict", method="POST").inc()
    INFERENCE_LATENCY.observe(random.uniform(0.005, 0.15))
```

Updated loop:

```python
for version in ("v1", "v1", "v1", "v2"):
    REQUEST_TOTAL.labels(
        version=version,
        endpoint="/predict",
        method="POST",
    ).inc()

    FRAUD_AMOUNT_TOTAL.labels(version=version).inc(
        random.uniform(10.0, 100.0)
    )

    INFERENCE_LATENCY.observe(random.uniform(0.005, 0.15))
```

This means every `_nudge_metrics()` tick advances the fraud amount totals for both model versions.

## MLOps issue encountered — Grafana query error

The initial error was:

```text
bad_data: invalid parameter "query":
parse error: unexpected character inside braces: '('
```

The screenshot showed the panel query entered in the **Prometheus Builder's Metric field** as:

```text
fraud_amount_usd_total{version=~"$version"}
```

The Builder interpreted the entire expression incorrectly.

### Fix

Switch the panel query editor from:

```text
Builder
```

to:

```text
Code
```

Then enter the raw PromQL:

```promql
fraud_amount_usd_total{version=~"$version"}
```

Also keep the variable query separate:

```promql
label_values(fraud_amount_usd_total, version)
```

### Critical distinction

**Variable query:**

```promql
label_values(fraud_amount_usd_total, version)
```

**Panel query:**

```promql
fraud_amount_usd_total{version=~"$version"}
```

Don't put the panel query into the variable configuration, and don't put the complete panel expression into the Builder's metric field.

# 3. Kubernetes — Grafana Deployment

## Objective

Create:

* Deployment: `grafana-deployment-devops`
* Grafana image
* 1 replica
* NodePort Service
* NodePort: `32000`

No namespace was specified, so the default namespace is sufficient.

---

## Step 1 — Create manifest

```bash
vi grafana.yaml
```

Use:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: grafana-deployment-devops
spec:
  replicas: 1
  selector:
    matchLabels:
      app: grafana
  template:
    metadata:
      labels:
        app: grafana
    spec:
      containers:
        - name: grafana
          image: grafana/grafana:latest
          ports:
            - containerPort: 3000
---
apiVersion: v1
kind: Service
metadata:
  name: grafana-service
spec:
  type: NodePort
  selector:
    app: grafana
  ports:
    - port: 3000
      targetPort: 3000
      nodePort: 32000
```
