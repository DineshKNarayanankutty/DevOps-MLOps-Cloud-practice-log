

```text
datacenter-sg
```

```text
HTTP (80)
Source: 0.0.0.0/0
```

---

#### Target Group

```text
Name: datacenter-tg
Protocol: HTTP
Port: 80
Target Type: Instance
```

Registered Target:

```text
datacenter-ec2
```

---

#### Application Load Balancer

```text
Name: datacenter-alb
Type: Application Load Balancer
Scheme: Internet-facing
Listener: HTTP:80
```

Forward Action:

```text
datacenter-tg
```


# MLOps

## MLflow Autologging

### Task

Enable automatic logging for:

```text
Parameters
Metrics
Artifacts
Models
```

Experiment:

```text
autolog-demo
```

---

### Configuration

Enable autologging:

```python
mlflow.sklearn.autolog()
```

Set experiment:

```python
mlflow.set_experiment("autolog-demo")
```

---

### Execution

```bash
python3 /root/code/autolog_experiment.py
```

Expected:

```text
Autolog run complete — check the MLflow UI
```

---

### Learning

Without autologging:

```python
mlflow.log_param()
mlflow.log_metric()
mlflow.sklearn.log_model()
```

must be written manually.

---

With autologging:

```python
mlflow.sklearn.autolog()
```

MLflow automatically captures:

```text
Model Parameters
Training Metrics
Model Artifacts
Environment Information
```

---

### Artifact Structure

```text
model/
├── MLmodel
├── model.pkl
└── environment files
```

---

### Real MLOps Workflow

```text
Model Training
      ↓
Autologging
      ↓
Experiment Tracking
      ↓
Model Review
      ↓
Model Registry
      ↓
Production Deployment
```
