# Kubernetes

## Topic: Set Up Time Check Pod in Kubernetes

### Objective

Deploy a BusyBox Pod that periodically writes timestamps using a ConfigMap.

---

## Steps Performed

Created ConfigMap

```bash
kubectl create configmap time-config \
--from-literal=TIME_FREQ=9 \
-n nautilus
```

Created Pod manifest

Configured

* Namespace
* BusyBox latest
* Container name
* ConfigMap environment variable
* emptyDir volume
* Volume mount

Command

```sh
while true
do
    date >> /opt/itadmin/time/time-check.log
    sleep $TIME_FREQ
done
```

Applied

```bash
kubectl apply -f time-check.yaml
```

Verified

```bash
kubectl get pods -n nautilus
```

Checked environment variable

```bash
kubectl exec -n nautilus \
time-check -- printenv TIME_FREQ
```

Checked log generation

```bash
kubectl exec -n nautilus \
time-check -- \
cat /opt/itadmin/time/time-check.log
```

---

## Key Learning

* ConfigMaps externalize configuration from container images.
* `emptyDir` volumes provide temporary storage throughout a pod's lifecycle.
