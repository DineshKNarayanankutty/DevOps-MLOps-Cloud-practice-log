## 2. Apache Default Page Behavior

### Learned

Apache serves files according to its `DirectoryIndex`.

If both files exist:

```
/var/www/html
│
├── index.html
└── index.php
```

Sometimes the default Apache page (`index.html`) is shown instead of the PHP application.

Deleting the default page solved the issue:

```bash
rm -f /var/www/html/index.html
```

# Terraform 🌍

## Variable-Based VPC Creation

### Objective

Created an AWS VPC using Terraform while separating configuration and values.

### Learned

Used:

```
variables.tf
```

to store:

* VPC Name
* CIDR Block

Referenced variables inside:

```
main.tf
```

---

### variables.tf

```hcl
variable "KKE_vpc" {
  type    = string
  default = "xfusion-vpc"
}

variable "vpc_cidr" {
  type    = string
  default = "10.0.0.0/16"
}
```

---

### main.tf

```hcl
provider "aws" {
  region = "us-east-1"
}

resource "aws_vpc" "xfusion_vpc" {
  cidr_block = var.vpc_cidr

  tags = {
    Name = var.KKE_vpc
  }
}
```

---

### Commands Used

```bash
cd /home/bob/terraform

vi variables.tf

vi main.tf

terraform init

terraform validate

terraform apply -auto-approve

terraform state list
```
