# 🔵 Azure

## Azure VM Internet Connectivity Troubleshooting

### Objective

Diagnose why package installation (`apt`) was failing.

---

### Connectivity Checklist Followed

Check IP:

```bash id="ppjlwm"
ip addr
```

---

Check Routes:

```bash id="e4idk7"
ip route
```

---

Ping Gateway:

```bash id="5eq0a7"
ping -c 4 <gateway>
```

---

Ping Internet:

```bash id="8l3hq4"
ping -c 4 8.8.8.8
```

---

DNS Test:

```bash id="g0sp2a"
ping google.com
```

---

Check Resolver:

```bash id="ytjlwm"
cat /etc/resolv.conf
```

---

Package Manager:

```bash id="ljlwmm"
sudo apt update
```

---

### Root Cause Identified

The VM's **Network Security Group** contained a custom outbound rule:

```text id="bljlwm"
Priority:
200

Rule:
Block-All-Outbound

Action:
Deny
```

Since Azure evaluates lower priority numbers first, this rule blocked all outbound traffic before the default internet allow rules.

---

### Resolution

Remove or disable the outbound deny rule so the VM can reach package repositories.

---
