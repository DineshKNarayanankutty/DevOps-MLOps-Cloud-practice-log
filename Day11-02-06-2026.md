# DevOps

## Deploy Java Application on Apache Tomcat

### Task

Installed Apache Tomcat on App Server 1, configured it to run on port **3004**, and deployed a Java application using **ROOT.war**.

### Commands Used

#### Copy WAR File

```bash
scp /tmp/ROOT.war tony@stapp01:/tmp/
```

#### Connect to App Server

```bash
ssh tony@stapp01
sudo su -
```

#### Install Tomcat

```bash
yum install -y tomcat tomcat-webapps tomcat-admin-webapps
```

#### Configure Port

```bash
vi /etc/tomcat/server.xml
```

Changed:

```xml
<Connector port="8080"
```

to:

```xml
<Connector port="3004"
```

#### Deploy Application

```bash
rm -rf /var/lib/tomcat/webapps/ROOT
rm -f /var/lib/tomcat/webapps/ROOT.war

cp /tmp/ROOT.war /var/lib/tomcat/webapps/
```

#### Start Service

```bash
systemctl enable tomcat
systemctl restart tomcat
```

#### Verification

```bash
systemctl status tomcat

ss -tulpn | grep 3004

curl http://stapp01:3004
```

# MLOps

## Move Dataset Tracking from Git to DVC

### Task

Migrated the dataset:

```text
data/raw/transactions.csv
```

from Git tracking to DVC tracking.

---

### Commands Used

#### Navigate to Repository

```bash
cd /root/code/fraud-detection
```

#### Verify Git Tracking

```bash
git ls-files data/raw/transactions.csv
```

#### Remove from Git Tracking

```bash
git rm --cached data/raw/transactions.csv
```

#### Add Dataset to DVC

```bash
dvc add data/raw/transactions.csv
```

Generated:

```text
data/raw/transactions.csv.dvc
data/raw/.gitignore
```

#### Stage Changes

```bash
git add data/raw/transactions.csv.dvc
git add data/raw/.gitignore
git add -u
```

#### Commit

```bash
git commit -m "Track transactions dataset with DVC"
```

#### Verification

```bash
git log --oneline -n 1

dvc status
```

---

### Why This Is Important

This follows standard MLOps practices:

* Git tracks metadata
* DVC tracks datasets
* Large files stay out of Git history
* Experiments become reproducible

# Terraform

## CloudWatch Alarm Creation

### Task

Create a CloudWatch alarm with:

| Setting            | Value               |
| ------------------ | ------------------- |
| Alarm Name         | nautilus-alarm      |
| Metric             | CPUUtilization      |
| Threshold          | 80%                 |
| Period             | 300 seconds (5 min) |
| Evaluation Periods | 1                   |

---

### Initial Attempt

Used a Terraform data source:

```hcl
data "aws_instance" "ec2" {
  filter {
    name   = "instance-state-name"
    values = ["running"]
  }
}
```

---

### What Went Wrong

Terraform failed:

```text
Error: no matching EC2 Instance found
```

Additional check:

```bash
terraform state list
```

returned:

```text
No state file was found
```

#### Root Cause

* No Terraform-managed resources existed.
* Terraform could not discover an EC2 instance through the data source.
* Assumed infrastructure was present when it was not.

---

### Troubleshooting

Checked Terraform state:

```bash
terraform state list
```

Checked for existing EC2 instances:

```bash
aws ec2 describe-instances \
  --region us-east-1 \
  --query 'Reservations[*].Instances[*].InstanceId' \
  --output text
```

---

### Final Terraform Configuration

```hcl
resource "aws_cloudwatch_metric_alarm" "nautilus_alarm" {
  alarm_name          = "nautilus-alarm"
  comparison_operator = "GreaterThanThreshold"
  evaluation_periods  = 1
  metric_name         = "CPUUtilization"
  namespace           = "AWS/EC2"
  period              = 300
  statistic           = "Average"
  threshold           = 80
}
```

# Key Lessons Learned

### DevOps

* `ROOT.war` deploys directly on the base URL.
* Tomcat port changes require a restart.

### MLOps

* Use `git rm --cached` when migrating files from Git to DVC.
* DVC pointer files and `.gitignore` become the artifacts tracked by Git.

### Terraform

* Always verify infrastructure existence before using Terraform data sources.
* `terraform state list` is one of the fastest ways to determine whether Terraform manages any resources.
* Troubleshooting often starts with validating assumptions before changing code.
