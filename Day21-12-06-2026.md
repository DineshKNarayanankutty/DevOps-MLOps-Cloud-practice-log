# Linux

## User and Group Management

### Task

Implement group-based access control across all App Servers.

Requirements:

```text
Group : nautilus_developers
User  : jarod
```

User must belong to:

```text
nautilus_developers
```

on:

```text
stapp01
stapp02
stapp03
```

---

### Commands Used

Create group:

```bash
groupadd nautilus_developers
```

Create user if missing:

```bash
useradd jarod
```

Add user to group:

```bash
usermod -aG nautilus_developers jarod
```

Verify:

```bash
id jarod
```

---

### Learning

Linux access control hierarchy:

```text
User
  ↓
Group
  ↓
Permissions
  ↓
Files / Services
```

This is the foundation of Linux RBAC (Role-Based Access Control).

```text
EC2 Instance
     ↓
```

