---

### Learning

SSH key authentication flow:

```text
aws-client
   ↓
id_rsa / id_rsa.pub
   ↓
authorized_keys
   ↓
EC2 Instance
```

Key files:

```text
Private Key : /root/.ssh/id_rsa
Public Key  : /root/.ssh/id_rsa.pub
```

Important permissions:

```text
/root/.ssh           700
authorized_keys      600
```

## What Was Learned

### MLflow Hierarchy

Before today, we mainly worked with:

```text
MLflow Server
     ↓
Runs
     ↓
Metrics
```

Today introduced the layer above runs:

```text
Experiment
     ↓
Runs
     ↓
Parameters
Metrics
Artifacts
```

---

## Why Experiments Exist

Without experiments:

```text
Default
 ├── Fraud Run #1
 ├── Fraud Run #2
 ├── Churn Run #1
 ├── Churn Run #2
 └── Forecast Run #1
```

Everything becomes mixed together.

With experiments:

```text
fraud-detection
 ├── Run #1
 ├── Run #2

churn-prediction
 ├── Run #1
 ├── Run #2
```

Projects remain isolated and easier to manage.
