## DevOps

### Nginx Load Balancer Configuration on LBR Server

#### Task

Configure the LBR server to load balance traffic across all application servers using Nginx.

Requirements:

* Install Nginx on `stlb01`
* Configure load balancing using all app servers
* Modify only `/etc/nginx/nginx.conf`
* Keep existing Apache ports unchanged
* Ensure Apache is running on all app servers
* Validate using:

```bash
curl http://stlb01
```

---

### Investigation

Initially discovered that the website was not reachable:

```bash
curl http://stlb01
```

Result:

```text
Connection refused
```

---

### Root Cause Analysis

Verified Apache port on App Server 1:

```bash
grep "^Listen" /etc/httpd/conf/httpd.conf
```

Output:

```text
Listen 3004
```

Earlier load balancer configuration was incorrectly pointing to:

```text
5001
```

instead of:

```text
3004
```

---

### Additional Issue

Inspection of `/etc/nginx/nginx.conf` showed:

```nginx
upstream backend {
    server stapp01:5001;
    server stapp02:5001;
    server stapp03:5001;
}
```

and the server block lacked:

```nginx
location / {
    proxy_pass http://backend;
}
```

As a result Nginx was serving its default content rather than acting as a reverse proxy.

---

### Fix

Updated backend servers to use correct Apache port:

```nginx
upstream backend {
    server stapp01:3004;
    server stapp02:3004;
    server stapp03:3004;
}
```

Configured reverse proxy:

```nginx
server {
    listen 80;

    location / {
        proxy_pass http://backend;
    }
}
```

Validated:

```bash
nginx -t
```

Restarted service:

```bash
systemctl restart nginx
```

---

### Learning

For load balancer tasks:

```text
Backend Port
      ↓
Must Match
      ↓
Apache Listen Port
```

Never assume:

```text
80
8080
8085
```

Always verify using:

```bash
grep "^Listen" /etc/httpd/conf/httpd.conf
```

## MLOps

### DVC Metrics Registration

#### Task

Configure DVC so that:

```bash
dvc metrics show
```

displays model metrics generated by:

```text
metrics.json
```

Requirements:

* Register metrics.json as a DVC metric
* Use `cache: false`
* Re-run pipeline
* Ensure DVC Metrics view can discover metrics

---

### Investigation

Current train stage:

```yaml
train:
  cmd: python src/models/train.py
  deps:
    - data/processed/train.csv
    - src/models/train.py
  outs:
    - models/model.pkl
    - metrics.json
```

Problem:

```text
metrics.json
```

was incorrectly registered as a normal output.

---

### Fix

Updated train stage:

```yaml
train:
  cmd: python src/models/train.py
  deps:
    - data/processed/train.csv
    - src/models/train.py

  outs:
    - models/model.pkl

  metrics:
    - metrics.json:
        cache: false
```

---

### Validation

Executed:

```bash
dvc repro
```

Verified:

```bash
dvc metrics show
```

Expected output:

```text
accuracy
f1_score
```

read directly from:

```text
metrics.json
```

---

### Learning

DVC artifacts fall into different categories:

| Type    | Purpose              |
| ------- | -------------------- |
| outs    | Data/model artifacts |
| metrics | Evaluation metrics   |
| params  | Hyperparameters      |

Metrics should generally use:

```yaml
cache: false
```

to allow Git-based history and comparison.

## Terraform

### AWS IAM Policy Creation

#### Task

Create IAM policy:

```text
iampolicy_mark
```

Requirements:

* Region: us-east-1
* Read-only EC2 access
* Allow viewing:

  * EC2 Instances
  * AMIs
  * Snapshots

---

### Terraform Configuration

Created:

```hcl
provider "aws" {
  region = "us-east-1"
}

resource "aws_iam_policy" "iampolicy_mark" {
  name = "iampolicy_mark"

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Effect = "Allow"
        Action = [
          "ec2:Describe*"
        ]
        Resource = "*"
      }
    ]
  })
}
```

---

### Deployment

Executed:

```bash
terraform init
terraform plan
terraform apply -auto-approve
```

---

### Learning

Read-only EC2 permissions are typically implemented using:

```json
"ec2:Describe*"
```

This grants visibility into:

```text
Instances
AMIs
Snapshots
Volumes
Security Groups
VPCs
```

without allowing modifications.

# Key Lessons Learned

### DevOps

* Verify backend ports before configuring load balancers.
* Nginx requires `proxy_pass` to function as a reverse proxy.
* `nginx -t` should always be run before restarting.

### MLOps

* Metrics should be registered under `metrics:`, not `outs:`.
* `cache: false` keeps metrics versioned in Git.

### Terraform

* IAM policies can be expressed cleanly using `jsonencode`.
* Least-privilege access often starts with read-only permissions.
