## Terraform

### AWS DynamoDB Table Creation

#### Task

Create DynamoDB table:

```text
nautilus-users
```

Requirements:

```text
Primary Key : nautilus_id
Type        : String
Billing     : PAY_PER_REQUEST
```

---

### Terraform Configuration

```hcl
provider "aws" {
  region = "us-east-1"
}

resource "aws_dynamodb_table" "nautilus_users" {
  name         = "nautilus-users"
  billing_mode = "PAY_PER_REQUEST"
  hash_key     = "nautilus_id"

  attribute {
    name = "nautilus_id"
    type = "S"
  }
}
```

---

### Deployment

```bash
terraform init
terraform plan
terraform apply -auto-approve
```

---

### Learning

DynamoDB essentials:

```text
Table
  ↓
Partition Key (Hash Key)
  ↓
On-Demand Billing
```

Using:

```hcl
billing_mode = "PAY_PER_REQUEST"
```

eliminates capacity planning and automatically scales with demand.
