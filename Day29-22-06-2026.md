## MLflow Artifact Store Troubleshooting

### Objective

Fix MLflow artifact uploads to SeaweedFS.

---

### Existing Components

```text
PostgreSQL
Port 5432

SeaweedFS
Port 8333 (S3 API)
Port 8888 (Filer UI)

MLflow
Port 5000
```

---

### Issue

Metadata successfully stored in:

```text
PostgreSQL
```

but artifacts were not uploaded.

---

### Root Cause

Missing environment variable:

```bash
export MLFLOW_S3_ENDPOINT_URL
```

MLflow attempted to use:

```text
AWS S3
```

instead of:

```text
SeaweedFS
```

---

### Fix

Added:

```bash
export MLFLOW_S3_ENDPOINT_URL=http://localhost:8333
```

to:

```text
/root/code/start-mlflow.sh
```

---

### Restart

```bash
bash /root/code/restart-mlflow.sh
```

---

### Validation

Executed:

```bash
python3 /root/code/log_test_run.py
```

Result:

```text
Experiment Created
Run Successful
Artifacts Uploaded
```

---

     ↓
