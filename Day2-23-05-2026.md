# AWS

## Create AWS Key Pair

### AWS Key Pair Resource

```hcl
resource "aws_key_pair" "datacenter_kp" {
  key_name   = "datacenter-kp"
  public_key = tls_private_key.datacenter_kp.public_key_openssh
}
```

# Terraform

## Store PEM File Locally

### Save Private Key Locally

```hcl
resource "local_file" "private_key" {
  filename        = "/home/bob/datacenter-kp.pem"
  content         = tls_private_key.datacenter_kp.private_key_pem

}

  default = true
}
```

++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

# AWS

## Security Group Creation

### Create Security Group

```hcl
resource "aws_security_group" "nautilus_sg" {
  name        = "nautilus-sg"
  description = "Security group for Nautilus App Servers"
  vpc_id      = data.aws_vpc.default.id
}
```

# AWS

## HTTP Ingress Rule

### Allow HTTP Traffic

```hcl
ingress {
  from_port   = 80
  to_port     = 80
  protocol    = "tcp"
  cidr_blocks = ["0.0.0.0/0"]
}
```
