# Linux Administration

## Create Non-Interactive User

### Connect to App Server

```bash
ssh steve@stapp02
```

### Become Root User

```bash
sudo su -
```

### Create Secure Non-Login User

```bash
useradd -s /sbin/nologin jim
```

### Verify User Shell

```bash
grep jim /etc/passwd
```

# JupyterLab Administration

## Jupyter Configuration Validation

### Set Jupyter Port

```python
c.ServerApp.port = 8888
```

### Allow External Access

```python
c.ServerApp.ip = '0.0.0.0'
```

### Configure Notebook Directory

```python
c.ServerApp.notebook_dir = '/root/notebooks'
```
