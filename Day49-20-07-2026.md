# Daily Learning Log – AWS DevOps Lab

**Date:** 2026-07-20

# Task

Configure secure log transfer from a private EC2 instance to an S3 bucket through a public EC2 instance using VPC Peering, SSH (SCP), IAM Roles, and Cron Jobs.

---

# Architecture

```text
Private EC2
     │
     │ SCP (boots.log)
     ▼
Public EC2
     │
     │ AWS CLI
     ▼
S3 Bucket
```

---

# Objective

* Create two VPCs
* Create one public subnet and one private subnet
* Launch EC2 instances
* Create VPC Peering
* Configure routing
* Configure SSH connectivity
* Transfer `/var/log/boots.log`
* Upload logs automatically to S3
* Automate everything using cron

# Step 17 — Configure SCP Cron Job on Private EC2

Edited cron

```bash
crontab -e
```

Initially added

```cron
* * * * * scp -o StrictHostKeyChecking=no /var/log/boots.log ubuntu@10.1.1.36:/home/ubuntu/boots.log
```

Issue

```
Permission denied (publickey)
```

Reason

Cron does not automatically use the PEM key.

Fixed cron

```cron
* * * * * scp -i /home/ubuntu/datacenter-key.pem -o StrictHostKeyChecking=no /var/log/boots.log ubuntu@10.1.1.36:/home/ubuntu/boots.log
```

Manual verification

```bash
scp -i /home/ubuntu/datacenter-key.pem \
-o StrictHostKeyChecking=no \
/var/log/boots.log \
ubuntu@10.1.1.36:/home/ubuntu/boots.log
```

Success.

# Issues Encountered & Fixes

| Issue                                           | Root Cause                              | Resolution                                                                 |
| ----------------------------------------------- | --------------------------------------- | -------------------------------------------------------------------------- |
| SSH identity file not found                     | Wrong PEM file path                     | Used `~/datacenter-key.pem`                                                |
| Unable to SSH to private EC2                    | Initially suspected networking          | Verified VPC peering, route tables, SGs, and NACLs; corrected SSH key path |
| SCP failed with `Permission denied (publickey)` | SSH key not specified in cron           | Added `-i /home/ubuntu/datacenter-key.pem`                                 |
| `boots.log` missing on public EC2               | SCP never completed                     | Fixed SCP command and verified transfer                                    |
| `aws` command not found                         | AWS CLI not installed                   | Installed `awscli`                                                         |
| `AccessDenied` during S3 upload                 | IAM role lacked S3 permissions          | Attached the required S3 permissions (per lab capabilities)                |
| Could not add inline IAM policy                 | Lab IAM user lacked `iam:PutRolePolicy` | Used the permissions mechanism allowed by the lab                          |
