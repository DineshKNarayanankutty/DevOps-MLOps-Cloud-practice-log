# 6. Linux — File Ownership Based Data Recovery

## Objective

Recover files owned by a specific user and preserve original structure.

---

## Source

```text
/home/usersdata
```

User:

```text
anita
```

Destination:

```text
/news
```

---

## Command Used

```bash
find /home/usersdata \
-type f \
-user anita \
-exec cp --parents {} /news \;
```

---

## Why --parents?

Without:

```text
file.txt
```

Only file copied.

With:

```text
Original Path Preserved
```

Example:

```text
/home/usersdata/project/docs/file.txt
```

becomes:

```text
/news/home/usersdata/project/docs/file.txt
```

---

## Key Learning

Useful for:

```text
User Data Recovery
Ownership Audits
Migration Tasks
Backup Restoration
```

---

## What I'll Remember

```bash
find -type f -user USER

cp --parents
```
