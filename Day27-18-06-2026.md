# DevOps

## Git Revert Workflow

### Objective

Undo the latest commit without rewriting Git history.

---

### Repository

```text
/usr/src/kodekloudrepos/official
```

---

### Requirement

Revert:

```text
HEAD
```

back to:

```text
Previous Commit
```

where previous commit was:

```text
initial commit
```

---

### Commands

Check history:

```bash
git log --oneline -2
```

Revert:

```bash
git revert HEAD
```

Modify commit message:

```bash
git commit --amend -m "revert official"
```

---

### Important Learning

Difference:

#### Revert

```text
Creates New Commit
Preserves History
```

#### Reset

```text
Removes History
Dangerous for Shared Repos
```

---

### What I'll Remember

```text
Undo Shared Commit
        ↓
git revert
```

not

```text
git reset
```

# Linux

## Disable Direct Root SSH Login

### Objective

Harden Linux servers by preventing direct root SSH access.

---

### Servers

```text
stapp01
stapp02
stapp03
```

---

### Configuration Updated

File:

```text
/etc/ssh/sshd_config
```

Changed:

```text
PermitRootLogin yes
```

to:

```text
PermitRootLogin no
```

---

### Commands

Edit:

```bash
sudo vi /etc/ssh/sshd_config
```

or

```bash
sudo sed -i \
's/^#\?PermitRootLogin.*/PermitRootLogin no/' \
/etc/ssh/sshd_config
```

Restart SSH:

```bash
sudo systemctl restart sshd
```

Verify:

```bash
grep "^PermitRootLogin" /etc/ssh/sshd_config
```

Expected:

```text
PermitRootLogin no
```

---

### Security Flow

Before:

```text
Internet
    ↓
Root Login
```

After:

```text
Internet
    ↓
Normal User
    ↓
sudo
    ↓
Root Access
```

---

### Key Learning

Industry best practice:

```text
Disable Root SSH
Use sudo
Audit User Access
```

---

### What I'll Remember

```text
PermitRootLogin no
```

is one of the first Linux hardening steps.
