## Objective

Create an EC2 instance and configure monitoring so operations teams receive notifications whenever CPU usage becomes abnormally high.

---

## What We Did

### Created EC2 Instance

```text
Name: devops-ec2
AMI: Ubuntu
State: Running
```

### Created CloudWatch Alarm

```text
Name: devops-alarm
```

Configuration:

```text
Metric: CPUUtilization
Statistic: Average
Threshold: >= 90%
Period: 5 Minutes
Evaluation Periods: 1
```

```text
devops-sns-topic
```

Flow:

```text
EC2
 ↓

 ↓

 ↓
Email / Notification
```


# 2. Azure — VM Storage Expansion

## Objective

Increase storage capacity of an existing VM.

---

## What We Did

### Expanded OS Disk

Before:

```text
32 GiB
```

After:

```text
64 GiB
```

---

### Created Additional Data Disk

```text
Disk Name: nautilus-disk
Disk Type: Standard HDD
Size: 64 GiB
```

Attached to:

```text
nautilus-vm
```

---

## Linux Side Configuration

### Verify New Disk

```bash
lsblk
```

Found:

```text
/dev/sdc
```

---

### Create Partition

```bash
sudo fdisk /dev/sdc
```

Steps:

```text
n
p
1
Enter
Enter
w
```

---

### Issue Encountered

Accidentally entered:

```text
w
```

at:

```text
First sector:
```

Result:

```text
Value out of range
```

Resolution:

```text
Press Enter
Use default sector values
Write partition table afterwards
```

---

### Format Partition

```bash
sudo mkfs.ext4 /dev/sdc1
```

---

### Create Mount Point

```bash
sudo mkdir -p /mnt/nautilus-disk
```

---

### Mount Disk

```bash
sudo mount /dev/sdc1 /mnt/nautilus-disk
```

Verify:

```bash
df -h
```

---

### Make Persistent

Find UUID:

```bash
sudo blkid /dev/sdc1
```

Output:

```text
UUID=a87a7a5e-8f8b-4781-b4d4-10d04e141380
```

Add to:

```bash
sudo vi /etc/fstab
```

Added:

```text
UUID=a87a7a5e-8f8b-4781-b4d4-10d04e141380 /mnt/nautilus-disk ext4 defaults,nofail 0 2
```

Validate:

```bash
sudo mount -a
```

---

## Key Learning

Linux storage lifecycle:

```text
Disk
 ↓
Partition
 ↓
Filesystem
 ↓
Mount
 ↓
fstab
```

---

## What I'll Remember

```bash
fdisk
mkfs.ext4
mount
/etc/fstab
```
