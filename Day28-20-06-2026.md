# AWS

## Amazon ECR Repository and Docker Image Push

### Objective

Create a private ECR repository and push a Docker image built from a Dockerfile.

---

### Resources

```text
ECR Repository:
datacenter-ecr
```

Dockerfile Location:

```text
/root/pyapp
```

Image Tag:

```text
latest
```

---

### What We Did

Created ECR Repository:

```text
datacenter-ecr
```

Built image:

```bash
cd /root/pyapp

docker build -t datacenter-ecr:latest .
```

---

### ECR Authentication

```bash
aws ecr get-login-password \
--region us-east-1 \
| docker login \
--username AWS \
--password-stdin <ecr-uri>
```

---

### Tagged Image

```bash
docker tag datacenter-ecr:latest \
<ecr-uri>/datacenter-ecr:latest
```

---

### Pushed Image

```bash
docker push \
<ecr-uri>/datacenter-ecr:latest
```

---

### Architecture

```text
Dockerfile
     ↓
docker build
     ↓
Local Image
     ↓
ECR Repository
     ↓
docker push
```

---

### Key Learning

Amazon ECR acts as:

```text
Private Docker Registry
```

inside AWS.

---

### What I'll Remember

```bash

```

# DevOps

## Git Cherry-Pick Workflow

### Objective

Move only a single commit from feature branch to master.

---

### Repository

```text
/opt/demo.git
```

Clone:

```text
/usr/src/kodekloudrepos/demo
```

---

### Requirement

Commit Message:

```text
Update info.txt
```

needed in:

```text
master
```

without merging entire branch.

---

### Commands

Find commit:

```bash
git checkout feature
git log --oneline
```

Switch:

```bash
git checkout master
```

Cherry-pick:

```bash
git cherry-pick <commit-id>
```

Push:

```bash
git push origin master
```

---

### Learning

Difference:

```text
Merge
```

brings:

```text
Entire Branch
```

while:

```text
Cherry-Pick
```

brings:

```text
Single Commit
```

### What I'll Remember

