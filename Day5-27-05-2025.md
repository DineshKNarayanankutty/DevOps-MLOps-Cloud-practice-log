# Problem Analysis

## Issues Identified in Existing Makefile

| Problem                        | Explanation                                            |
| ------------------------------ | ------------------------------------------------------ |
| Missing `.PHONY`               | Make may confuse targets with actual files/directories |
| Incorrect indentation          | Makefiles require TAB characters, not spaces           |
| Missing `data` target in `all` | Full workflow not executed                             |
| Incomplete cleanup             | Did not remove pytest cache/models properly            |
| pytest missing                 | Virtual environment lacked testing dependency          |
| Inconsistent Python execution  | Commands not fully isolated to virtual environment     |

# Understanding Each Workflow Stage

# 1. setup

## Purpose

Creates isolated Python environment and installs dependencies.

### Commands

```make id="uiw3"
python3 -m venv mlops-venv
```

Creates virtual environment:

```text id="uiw4"
mlops-venv/
```

---

### Install Project Dependencies

```make id="uiw5"
mlops-venv/bin/pip install -r requirements.txt
```

Installs:

* scikit-learn
* pandas
* numpy
* mlflow

---

### Install Testing Framework

```make id="uiw6"
mlops-venv/bin/pip install pytest
```

Needed for automated test execution.

---

## Why This Matters in MLOps

Without isolated environments:

* dependency conflicts occur,
* reproducibility breaks,
* training behaves differently across machines,
* CI/CD pipelines become unstable.

Virtual environments ensure:

* consistent builds,
* reproducible experiments,
* stable deployments.

---

# 5. clean

## Purpose

Removes generated temporary files and artifacts.

### Remove Python Cache

```make id="uixc"
find . -type d -name "__pycache__" -exec rm -rf {} +
```

Python automatically creates:

```text id="uixd"
__pycache__/
```

These are compiled bytecode caches.

Safe to remove.

---

### Remove pytest Cache

```make id="uixe"
rm -rf .pytest_cache
```

Removes testing framework cache.

---

### Remove Old Models

```make id="uixf"
rm -rf models/*
```

Deletes stale model artifacts.

---

## Why Cleanup Matters

Without cleanup:

* old models may be reused accidentally,
* storage grows unnecessarily,
* debugging becomes harder,
* reproducibility decreases.

---

# 6. all

## Purpose

Master orchestration workflow.

### Definition

```make id="uixg"
all: setup data train test
```

---

## Execution Order

Running:

```bash id="uixh"
make all
```

automatically performs:

1. setup
2. data
3. train
4. test

---

# Why `.PHONY` is Important

```make id="uixi"
.PHONY: setup data train test clean all
```

---

## Problem Without `.PHONY`

If a file named:

```text id="uixj"
test
```

exists,
Make may incorrectly think:

```text id="uixk"
Target already exists, skipping execution
```

This causes inconsistent automation behavior.

---

## `.PHONY` Fixes This

It tells Make:

> These are workflow tasks, not files.

---

# Why TAB Characters Matter

Makefiles require REAL TAB indentation.

Incorrect:

```make id="uixl"
data:
    python script.py
```

(Spaces)

Correct:

```make id="uixm"
data:
	python script.py
```

(Tab)
