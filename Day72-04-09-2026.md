## Task: Deployment Rolling Update and Rollback

### Requirements

Namespace:

```text
xfusion
```

Deployment:

```text
Name: httpd-deploy
Container: httpd
Image: httpd:2.4.25
Replicas: 4
```

Strategy:

```text
RollingUpdate
maxSurge: 1
maxUnavailable: 2
```

Service:

```text
Name: httpd-service
Type: NodePort
NodePort: 30008
```

Then:

```text
httpd:2.4.25
      ↓
httpd:2.4.43
      ↓
rollback
      ↓
httpd:2.4.25
```

---

## Step 1 — Create Namespace

```bash
kubectl create namespace xfusion
```

Verify:

```bash
kubectl get namespace xfusion
```

---

## Step 2 — Create Manifest

```bash
vi httpd-deploy.yaml
```

Use:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: httpd-deploy
  namespace: xfusion
spec:
  replicas: 4
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 2
  selector:
    matchLabels:
      app: httpd
  template:
    metadata:
      labels:
        app: httpd
    spec:
      containers:
        - name: httpd
          image: httpd:2.4.25
          ports:
            - containerPort: 80
---
apiVersion: v1
kind: Service
metadata:
  name: httpd-service
  namespace: xfusion
spec:
  type: NodePort
  selector:
    app: httpd
  ports:
    - port: 80
      targetPort: 80
      nodePort: 30008
```

## Task: SNS Topic + CloudWatch CPU Alarm

### Requirements

SNS:

```text
Name: xfusion-sns-topic
```

CloudWatch:

```text
Alarm: xfusion-cpu-alarm
Metric: CPUUtilization
Threshold: 80%
Actions: Enabled
SNS notification: xfusion-sns-topic
```

---

## Step 1 — `main.tf`

All resources were kept in `main.tf`.

```hcl
resource "aws_sns_topic" "xfusion_sns_topic" {
  name = "xfusion-sns-topic"
}

resource "aws_cloudwatch_metric_alarm" "xfusion_cpu_alarm" {
  alarm_name          = "xfusion-cpu-alarm"
  comparison_operator = "GreaterThanThreshold"
  evaluation_periods  = 1
  metric_name         = "CPUUtilization"
  namespace           = "AWS/EC2"
  period              = 300
  statistic           = "Average"
  threshold           = 80

  alarm_description = "Alarm when EC2 CPU utilization exceeds 80%"

  alarm_actions = [
    aws_sns_topic.xfusion_sns_topic.arn
  ]

  actions_enabled = true
}
```

### Important configuration

```text
Metric:
CPUUtilization

Statistic:
Average

Period:
300 seconds = 5 minutes

Threshold:
80

Comparison:
GreaterThanThreshold

Evaluation periods:
1

Actions:
Enabled
```

Therefore:

```text
CPUUtilization > 80%
        ↓
1 × 5-minute evaluation period
        ↓
Alarm
        ↓
SNS notification
```
