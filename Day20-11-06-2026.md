# Today's Log — 11/06/2026 - Day 20

## DevOps

### Nginx + PHP-FPM Application Deployment

#### Task

Prepare App Server 1 for a PHP application.

Requirements:

```text
Nginx Port      : 8094
Document Root   : /var/www/html
PHP-FPM Socket  : /var/run/php-fpm/default.sock
```

Application files already existed:

```text
/var/www/html/index.php
/var/www/html/info.php
```

---

### Initial Issue

PHP-FPM was configured correctly:

```ini
listen = /var/run/php-fpm/default.sock
listen.owner = nginx
listen.group = nginx
```

but Nginx returned:

```text
The page is temporarily unavailable
```

(50x error page)

---

### Root Cause Analysis

Nginx configuration showed:

```nginx
root /usr/share/nginx/html;
```

instead of:

```nginx
root /var/www/html;
```

and there was **no PHP location block**.

As a result:

```text
Nginx
  ↓
Receives .php request
  ↓
Doesn't know how to process PHP
  ↓
Returns 50x error
```

---

### Fix

Updated Nginx:

```nginx
root /var/www/html;
index index.php index.html;
```

Added PHP handler:

```nginx
location ~ \.php$ {
    fastcgi_pass unix:/var/run/php-fpm/default.sock;
    fastcgi_index index.php;
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
}
```

---

### Learning

PHP request flow:

```text
Browser
   ↓
Nginx
   ↓
PHP-FPM Socket
   ↓
PHP Interpreter
   ↓
HTML Response
```

A very common DevOps troubleshooting scenario.

## MLOps

### MLflow Tracking Server Deployment

#### Task

Deploy MLflow Tracking Server.

Requirements:

```text
Port            : 5000
Backend Store   : SQLite
Artifacts       : Local Filesystem
Accessible      : All Interfaces
```

---

### Directory Preparation

Created:

```bash
mkdir -p /root/code/mlflow-backend
mkdir -p /root/code/mlflow-artifacts
```

---

### MLflow Startup

```bash
nohup mlflow server \
  --host 0.0.0.0 \
  --port 5000 \
  --backend-store-uri sqlite:////root/code/mlflow-backend/mlflow.db \
  --artifacts-destination /root/code/mlflow-artifacts \
  --cors-allowed-origins '*' \
  --allowed-hosts '*' \
  > /root/mlflow.log 2>&1 &
```

### Learning

IAM Role structure:

```text
Role
   ↓
Trust Policy
   ↓
Permissions Policy
```

Trust Policy:

```text
Who can assume the role?
```

Permissions Policy:

```text
What can the role do?
```

For EC2:

```json
{
  "Service": "ec2.amazonaws.com"
}
```

---

### Real World Example

```text
EC2 Instance
     ↓
Assume IAM Role
     ↓
Access S3
Access DynamoDB
Access SSM
```

without storing credentials on the server.
