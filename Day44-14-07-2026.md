# Issues Encountered Today

# Biggest Lessons Today

### AWS

Auto Scaling Groups and Application Load Balancers work together to provide self-healing and scalable web infrastructure by combining automatic instance provisioning with intelligent traffic distribution.

### Azure

Event Hubs decouples log producers from consumers, enabling applications to publish events once while allowing multiple downstream systems to process them independently.

### MLOps

Centralized secrets management with HashiCorp Vault eliminates hardcoded credentials and supports secure credential rotation without rebuilding applications.

### DevOps

Docker Compose simplifies multi-configuration container deployments and makes infrastructure reproducible by storing container definitions in version-controlled YAML files.

### Kubernetes

Deployment rollback is a critical production capability that enables rapid recovery from faulty releases by restoring a previous ReplicaSet.

### Linux

The SetGID permission bit is essential for collaborative directories because it guarantees consistent group ownership for all newly created files, simplifying team-based access control.
