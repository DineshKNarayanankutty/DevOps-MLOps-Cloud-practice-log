# Linux

## Configuring User Process Limits

### Objective

Protect server resources by limiting the maximum number of processes the `nfsuser` account can create.

---

## Server

```text
Application Server 1
```

---

## Configuration File

```text
/etc/security/limits.conf
```

---

## Commands Executed

SSH:

```bash
ssh app1
```

Edit:

```bash
sudo vi /etc/security/limits.conf
```

Added:

```text
nfsuser soft nproc 1025

nfsuser hard nproc 2024
```

Alternative:

```bash
echo "nfsuser soft nproc 1025" | sudo tee -a /etc/security/limits.conf

echo "nfsuser hard nproc 2024" | sudo tee -a /etc/security/limits.conf
```

Verify:

```bash
grep "^nfsuser" /etc/security/limits.conf
```

---

## Resource Flow

```text
User Login
      │
PAM
      │
limits.conf
      │
Soft Limit: 1025
Hard Limit: 2024
      │
Maximum Allowed Processes
```

---

## Key Learning

Linux uses `/etc/security/limits.conf` to control per-user resource consumption, helping prevent a single user or application from exhausting system resources.

# Issues Encountered Today

### MLOps Pipeline

The pipeline generated features from the raw dataset instead of the cleaned dataset because the featurization stage referenced the wrong input path. Updating the stage to consume the processed dataset restored the intended pipeline flow and ensured consistent row counts.

### Azure Connectivity

Successful PHP-to-MySQL connectivity required three coordinated changes: opening TCP port **3306** in the MySQL VM's NSG, creating the MySQL user as `'xfusion_user'@'%'` to allow remote connections, and updating `db_test.php` to use the MySQL VM's public IP and pass the `$port` variable to `mysqli`.

# Biggest Lessons Today

### AWS

IAM Roles are the recommended mechanism for granting EC2 instances secure, temporary access to AWS services such as S3 without embedding long-lived credentials.

### Azure

Application-to-database communication depends on correct networking, firewall rules, database permissions, and application configuration working together.

### DevOps

`docker cp` provides a simple and reliable way to transfer files between the host and a running container without altering the file contents.

### MLOps

Maintaining correct stage dependencies is critical in ML pipelines; each stage should consume the output of its immediate predecessor to ensure reproducible and trustworthy results.

### Terraform

Separating variables into `variables.tf` improves readability, reuse, and maintainability of Infrastructure as Code.

### Linux

Setting soft and hard process limits is a practical system-hardening technique that protects shared servers from excessive resource consumption by individual users or applications.
